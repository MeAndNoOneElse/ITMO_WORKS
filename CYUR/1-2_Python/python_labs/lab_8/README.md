# Лабораторная работа №8 – OpenCV (Вариант 9)

## Задание по варианту

1. **Преобразование изображения:**  
   Построить **пирамиду изображений** (несколько уровней масштабирования).

2. **Отслеживание метки:**  
   Реализовать поиск напечатанной метки в видеопотоке с камеры.

3. **Модификация для варианта 9:**  
   Выводить в консоль **среднюю координату** положения метки за текущий сеанс работы.

## Структура программы

- `main.py` – главное меню для выбора режимов  
- `pyramid.py` – построение пирамиды изображений (режим 1)  
- `marker.py` – отслеживание плоской метки + **вывод средней координаты** (режим 2)  
- `rubiks_new.py` – бонусное отслеживание грани кубика Рубика (режим 3)  

## Как запустить

```bash
python main.py

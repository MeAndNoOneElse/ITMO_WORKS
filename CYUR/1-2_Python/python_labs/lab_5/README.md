# Лабораторная работа №5

В ходе лабораторной работы выполнил обработку текстовых, html и "шумовых" файлов с применением регулярных выражений:

- Для задания 1 выделил слова, оканчивающиеся на "e", и числа в круглых скобках.
- Для задания 2 извлёк все размеры изображений из HTML-файла.
- Для задания 3 спарсил перемешанную базу в правильную таблицу (ID, фамилия, email, дата, сайт) с последовательным разбором.
- В дополнительном задании нашёл 5 дат, 5 email и 5 сайтов среди случайных символов.

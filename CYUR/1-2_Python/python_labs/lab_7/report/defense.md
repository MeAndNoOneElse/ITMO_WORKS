# Ответы на вопросы для защиты — Лабораторная №7

## 1. Что такое API?

**API (Application Programming Interface)** — набор готовых функций/эндпоинтов, которые одна программа предоставляет другим программам для взаимодействия. Веб-API работает поверх HTTP: клиент отправляет запрос, сервер возвращает ответ (обычно JSON).

---

## 2. Что такое REST API?

**REST (Representational State Transfer)** — архитектурный стиль веб-API. Основные принципы:
- Ресурсы адресуются через URL
- Используются стандартные HTTP-методы (GET, POST, PUT, DELETE)
- Ответ в формате JSON
- Без сохранения состояния между запросами (stateless)

Примеры из лабораторной: OpenWeatherMap, Rick and Morty API, cataas.com — все REST API.

---

## 3. Какие HTTP-методы существуют и какие использовались в работе?

- **GET** — получение данных (все наши запросы)
- **POST** — отправка данных на сервер
- **PUT** — обновление ресурса
- **DELETE** — удаление ресурса

В лабораторной использовался только **GET**, так как мы только получаем данные.

---

## 4. Что такое HTTP-статус коды?

Числовой код состояния ответа сервера:
- **200 OK** — успешный запрос
- **400 Bad Request** — некорректный запрос (неверные параметры)
- **401/403** — ошибка авторизации
- **404 Not Found** — ресурс не найден
- **500 Internal Server Error** — ошибка сервера

В коде: `response.raise_for_status()` выбрасывает исключение при статусе >= 400.

---

## 5. Как работать с HTTP в Python?

Через библиотеку `requests`:

```python
import requests

response = requests.get("https://api.example.com/data", params={"key": "value"}, timeout=10)
response.raise_for_status()  # проверка на ошибки
data = response.json()       # парсинг JSON
```

Параметр `params` автоматически формирует query string `?key=value`. Параметр `timeout` ограничивает время ожидания ответа.

---

## 6. Что такое JSON?

**JSON (JavaScript Object Notation)** — текстовый формат обмена данными. В Python:
- `{}` в JSON → `dict`
- `[]` в JSON → `list`
- `"string"` → `str`
- `123` → `int`, `12.3` → `float`
- `true/false` → `True/False`
- `null` → `None`

Метод `response.json()` из `requests` автоматически парсит JSON в Python-объекты.

---

## 7. Какие типы ошибок обрабатываются в программе?

- **Сетевые ошибки** — `requests.RequestException` (нет интернета, сервер недоступен, таймаут)
- **Ошибки парсинга** — `ValueError`, `KeyError` (некорректный JSON или отсутствие ожидаемого поля)
- **Логические ошибки** — проверка `data.get("cod") != 200` для OpenWeatherMap, `data.get("results")` для Rick and Morty

Все ошибки обрабатываются через `try/except`, программа не падает, а выводит сообщение пользователю.

## 8. Как работает генератор котиков с анимацией GIF?

1. Отправляется GET-запрос на `https://cataas.com/cat/gif` — сервер возвращает бинарные данные GIF
2. Через `PIL.Image.open(BytesIO(data))` открывается изображение из памяти
3. Если формат GIF — кадры извлекаются через `gif.seek(gif.tell() + 1)` до `EOFError`
4. Для каждого кадра берётся задержка из `gif.info["duration"]`
5. Кадры последовательно показываются в `tkinter.Label` через `root.after(delay, callback)` — это планировщик событий tkinter

---

## 9. Почему tkinter не анимирует GIF автоматически и как это решено?

`tkinter.PhotoImage` загружает только первый кадр GIF. Решение: извлечь все кадры через `PIL.Image`, создать для каждого `ImageTk.PhotoImage`, и переключать их с нужной задержкой через метод `after()`.

---

## 10. Зачем нужен параметр `timeout` в запросах?

`timeout` ограничивает время ожидания ответа от сервера. Без него программа может зависнуть навсегда при недоступности сервера. Указан в секундах: `timeout=10` — ждать максимум 10 секунд.

---

## 11. Для чего нужен API-ключ в OpenWeatherMap?

API-ключ (`appid`) — механизм авторизации. Сервер проверяет, что запрос пришёл от зарегистрированного пользователя, и лимитирует количество запросов. Без ключа API вернёт **401 Unauthorized**.

---

## 12. Как работает меню программы?

Бесконечный цикл `while True` с словарём заданий. Пользователь вводит номер, вызывается соответствующая функция через `func()`. После завершения — снова меню. Выход по `q`.

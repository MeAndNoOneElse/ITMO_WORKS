# Lab-7

## Лабораторная работа №7 — Работа с API

### Описание

Программа взаимодействует с тремя внешними REST API:

| Задание | API | Описание |
|---------|-----|----------|
| 1 | OpenWeatherMap | Показывает погоду в указанном городе |
| 2 | Rick and Morty API | Поиск персонажа или случайный персонаж |
| 3 (бонус) | cataas.com | Генератор случайных GIF-картинок с котом |

### Структура

```
lab_7/
├── programm/
│   ├── main.py          # Основной код программы
│   └── test_main.py     # Тесты (pytest)
├── report/
│   ├── report.tex       # Отчёт (LaTeX)
│   └── defense.md       # Ответы на вопросы для защиты
├── task/                # Условие задания
└── README.md
```

### Требования

```
pip install requests pillow pytest
```

### Запуск

```bash
python main.py
```

После запуска появится меню выбора задания. Каждое задание можно запускать многократно.

```
Выберите задание:
  1 — Погода в городе
  2 — Персонаж Rick and Morty
  3 — Генератор котиков
  q — выход
```

### Тесты

```bash
pytest test_main.py -v
```

Тесты проверяют корректность запросов к реальным API с живыми сервисами.

### Отчёт

- Отчёт: `report/report.tex` — скомпилировать через `pdflatex report.tex`
- Ответы для защиты: `report/defense.md`

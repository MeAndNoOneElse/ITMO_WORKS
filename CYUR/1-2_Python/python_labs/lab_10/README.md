ude# Лабораторная работа №10 - Голосовые ассистенты

## Описание проекта

Проект содержит два голосовых ассистента на основе Python:

1. **Ассистент погоды** (основное задание) - получает информацию о погоде в Санкт-Петербурге и рекомендует, идти ли на прогулку
2. **Ассистент словаря** (дополнительное задание) - поиск определений английских слов через API

## Требования

Для работы необходимо установить следующие библиотеки:

```bash
pip install requests pyttsx3 SpeechRecognition
```

### Системные требования
- Python 3.7+
- Микрофон для распознавания речи
- Динамик для синтеза речи
- Интернет-соединение

## Файлы проекта

### main.py
Главный файл с меню для выбора ассистента.

**Запуск:**
```bash
python main.py
```

### voice_weather_assistant.py
Ассистент погоды для Санкт-Петербурга.

**Основные команды:**
- `погода` - получить текущую температуру и описание погоды
- `ветер` - узнать скорость ветра
- `направление` - узнать направление ветра
- `записать` - сохранить информацию о погоде в файл `weather_log.txt`
- `прогулка` - получить рекомендацию о прогулке
- `помощь` - список команд
- `выход` - завершить работу

**Пороги для рекомендации прогулки:**
- Минимальная температура: +5°C
- Максимальная скорость ветра: 15 км/ч

**Пример использования:**
```bash
python voice_weather_assistant.py
```

### voice_dictionary_assistant.py
Ассистент для поиска английских слов в словаре.

**Основные команды:**
- `find <word>` - найти слово в словаре
- `meaning` - произнести определение текущего слова
- `example` - произнести примеры использования слова
- `link` - открыть источник информации о слове в браузере
- `save` - сохранить информацию о слове в файл `dictionary_words.json`
- `help` - список команд
- `exit` - завершить работу

**Пример использования:**
```bash
python voice_dictionary_assistant.py
```

## Архитектура

### WeatherAssistant (voice_weather_assistant.py)
```
WeatherAssistant
├── speak() - синтез речи
├── listen() - распознавание речи
├── get_weather() - получение данных о погоде
├── extract_weather_info() - обработка данных
├── handle_*_command() - обработчики команд
└── process_command() - маршрутизация команд
```

### DictionaryAssistant (voice_dictionary_assistant.py)
```
DictionaryAssistant
├── speak() - синтез речи
├── listen() - распознавание речи (английский)
├── search_word() - поиск слова в словаре
├── handle_*_command() - обработчики команд
└── process_command() - маршрутизация команд
```

## Обработка ошибок

Оба ассистента обрабатывают следующие ошибки:

1. **Ошибки распознавания речи:**
   - Если речь не распознана → "Извините, я не смог распознать вашу команду"
   - Если ошибка сервиса → сообщение об ошибке с деталями

2. **Ошибки получения данных:**
   - Если слово не найдено в словаре → "The word was not found in the dictionary"
   - Если ошибка доступа к API → сообщение об ошибке

3. **Ошибки сохранения файлов:**
   - Перехватываются и выводится сообщение об ошибке

4. **Неизвестные команды:**
   - Выводится сообщение "Команда не распознана"

## API и источники данных

### Погода
- Источник: `https://wttr.in/Saint-Petersburg?format=j1`
- Формат: JSON
- Получаемые данные: температура, описание погоды, скорость ветра, направление ветра, влажность

### Словарь
- Источник: `https://api.dictionaryapi.dev/api/v2/entries/en/{word}`
- Формат: JSON
- Получаемые данные: определения, примеры, источники

## Файлы выходных данных

1. **weather_log.txt** - создается при команде "записать"
   - Формат: простой текст с информацией о погоде

2. **dictionary_words.json** - создается при команде "save" (словарь)
   - Формат: JSON с полной информацией о словах

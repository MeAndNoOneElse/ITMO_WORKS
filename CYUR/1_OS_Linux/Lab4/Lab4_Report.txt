# Лабораторная работа 4: Управление пользователями и группами в Linux

### Этап 1: Изучение структуры файла /etc/passwd

**Описание:** Файл /etc/passwd содержит информацию обо всех пользователях системы. Каждая строка представляет одного пользователя и состоит из следующих полей, разделённых двоеточиями:

- **Имя пользователя** — уникальный идентификатор для входа
- **Пароль (x)** — символ 'x' означает, что пароль хранится в /etc/shadow
- **UID (User ID)** — числовой идентификатор пользователя
- **GID (Group ID)** — числовой идентификатор первичной группы
- **GECOS (комментарий)** — информация о пользователе (ФИО, контакты)
- **Домашний каталог** — путь к домашней директории пользователя
- **Shell** — оболочка командной строки, используемая пользователем при входе

**Команда:**
```bash
sudo cat /etc/passwd
```

**Вывод:**
```
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin
sys:x:3:3:sys:/dev:/usr/sbin/nologin
sync:x:4:65534:sync:/bin:/bin/sync
games:x:5:60:games:/usr/games:/usr/sbin/nologin
man:x:6:12:man:/var/cache/man:/usr/sbin/nologin
lp:x:7:7:lp:/var/spool/lpd:/usr/sbin/nologin
mail:x:8:8:mail:/var/mail:/usr/sbin/nologin
news:x:9:9:news:/var/spool/news:/usr/sbin/nologin
uucp:x:10:10:uucp:/var/spool/uucp:/usr/sbin/nologin
```

**Анализ примера строки (root):**
```
root:x:0:0:root:/root:/bin/bash
```
- **root** — имя пользователя (администратор системы)
- **x** — пароль хранится отдельно в /etc/shadow
- **0** — UID = 0 (главный администратор)
- **0** — GID = 0 (группа root)
- **root** — описание (комментарий)
- **/root** — домашний каталог администратора
- **/bin/bash** — используется командная оболочка Bash

### Этап 4: Создание группы Students

**Описание:** Создаётся новая группа Students для организации доступа к общим ресурсам и файлам.

**Команда:**
```bash
sudo groupadd Students
```

**Проверка создания группы:**
```bash
cat /etc/group | grep Students
```

**Вывод:**
```
Students:x:1004:
```

**Анализ:**
- Группа Students успешно создана с GID 1004
- Поле членства группы пусто, так как пользователи ещё не добавлены

### Этап 5: Добавление пользователей в группу Students

**Описание:** Все три пользователя добавляются в группу Students для предоставления им прав доступа к ресурсам этой группы.

**Команды:**
```bash
sudo usermod -aG Students ivanov1
sudo usermod -aG Students ivanov2
sudo usermod -aG Students ivanov3
```

**Проверка членства:**
```bash
cat /etc/group | grep Students
```

**Вывод:**
```
Students:x:1004:ivanov1,ivanov2,ivanov3
```

**Анализ:**
- Все три пользователя успешно добавлены в группу Students
- Ключ `-aG` означает:
  - `-a` — добавить (append), а не заменить
  - `-G` — вторичные группы (дополнительно к первичной группе)

### Этап 9: Изменение владельца файла schedule (группа)

**Описание:** Файл schedule переводится в собственность группы Students, чтобы все члены группы имели доступ к нему.

**Первая попытка (без sudo):**
```bash
chgrp Students schedule
```

**Вывод ошибки:**
```
chgrp: изменение группы для 'schedule': Операция не позволена
```

**Вторая попытка (с sudo):**
```bash
sudo chgrp Students schedule
```

**Проверка результата:**
```bash
ls -l schedule
```

**Вывод:**
```
-rw-rw-r-- 1 eter Students 56 ноя  4 22:09 schedule
```

**Анализ прав доступа (-rw-rw-r--):**
- **-** — обычный файл (не директория)
- **rw-** — владелец (eter): чтение и запись
- **rw-** — группа (Students): чтение и запись
- **r--** — остальные: только чтение

### Этап 13: Изменение прав доступа к файлу important

**Описание:** Устанавливаются права 660 (rw-rw----), что позволяет читать и писать только владельцу и группе, отрицая доступ остальным. Файл переводится в собственность группы important.

**Команды:**
```bash
sudo chmod 660 important
sudo chgrp important important
```

**Проверка:**
```bash
ls -l important
```

**Вывод:**
```
-rw-rw---- 1 eter important 5 ноя  4 22:31 important
```

**Анализ прав доступа (-rw-rw----)):**
- **-** — обычный файл
- **rw-** — владелец (eter): чтение и запись
- **rw-** — группа (important): чтение и запись
- **---** — остальные: доступ запрещён

**Значение прав 660 в численном формате:**
- 6 (владелец) = 4(r) + 2(w) + 0(x)
- 6 (группа) = 4(r) + 2(w) + 0(x)
- 0 (остальные) = 0(r) + 0(w) + 0(x)

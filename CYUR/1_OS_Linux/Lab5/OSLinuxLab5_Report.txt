## 7. Создание юнит-файла eyes-relax.service

### Команда:
```bash
cat > eyes-relax.service << 'EOF'
[Unit]
Description=Eyes Relax Notification Service
After=display-manager.service

[Service]
Type=oneshot
ExecStart=/home/eter/bin/eyes-start.sh
Environment=DISPLAY=:0
Environment=DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/1000/bus

[Install]
WantedBy=default.target
EOF
```

**Пояснение:**
- **[Unit]** — метаинформация о юните
  - `Description` — описание сервиса
  - `After=display-manager.service` — убедиться, что X11 уже запущен, чтобы уведомления выводились корректно
- **[Service]** — параметры запуска сервиса
  - `Type=oneshot` — сервис выполняется один раз и завершается (не постоянно работающий демон)
  - `ExecStart=/home/eter/bin/eyes-start.sh` — команда для выполнения (путь к нашему скрипту)
  - `Environment=DISPLAY=:0` — необходимо для отправки уведомлений в X11
  - `Environment=DBUS_SESSION_BUS_ADDRESS` — адрес для связи с D-Bus (для notify-send)
- **[Install]** — как устанавливать сервис
  - `WantedBy=default.target` — сервис желаемо загружается при старте пользовательской сессии

## 8. Создание юнит-файла eyes-relax.timer

### Команда:
```bash
cat > eyes-relax.timer << 'EOF'
[Unit]
Description=Eyes Relax Timer
Requires=eyes-relax.service

[Timer]
OnBootSec=52s
OnUnitActiveSec=52s

[Install]
WantedBy=timers.target
EOF
```

**Пояснение:**
- **[Unit]** — метаинформация
  - `Description` — описание таймера
  - `Requires=eyes-relax.service` — таймер требует наличия сервиса `eyes-relax.service`
- **[Timer]** — параметры срабатывания таймера
  - `OnBootSec=52s` — срабатывает через 52 секунды после загрузки системы
  - `OnUnitActiveSec=52s` — срабатывает каждые 52 секунды после последнего срабатывания (соответствует варианту)
- **[Install]** — установка
  - `WantedBy=timers.target` — таймер включается при загрузке пользовательских таймеров

## 10. Перемещение скриптов в папку без пробелов в пути

### Проблема, которая была обнаружена:

При первом запуске таймера возникла ошибка:
```
Failed to locate executable /home/eter/Рабочий: No such file or directory
```

**Причина:** В юнит-файлах `eyes-relax.service` был указан путь `/home/eter/Рабочий стол/eyes-start.sh`, но systemd не корректно обрабатывает пути с пробелами в названии папки.

### Решение:

Копируем скрипты в папку `~/bin`, которая не содержит пробелов:

```bash
mkdir -p ~/bin
cp ~/Рабочий\ стол/eyes-start.sh ~/bin/
cp ~/Рабочий\ стол/eyes-stop.sh ~/bin/
chmod +x ~/bin/eyes-*.sh
ls -l ~/bin/eyes-*.sh
```

**Результат:**
```
-rwxrwxr-x 1 eter eter 222 ноя  4 23:16 /home/eter/bin/eyes-start.sh
-rwxrwxr-x 1 eter eter  51 ноя  4 23:16 /home/eter/bin/eyes-stop.sh
```

### Обновление юнит-файлов с корректными путями:

Переходим в папку с юнит-файлами:
```bash
cd ~/.config/systemd/user
```

Обновляем `eyes-relax.service`:

# Лабораторная работа № 3: Написание составных команд в bash

## Введение

В данной лабораторной работе изучены основные потоки в Linux (STDIN - 0, STDOUT - 1, STDERR - 2), способы их перенаправления, использование пайплайнов для связи команд, работа с переменными и потоковая обработка текстовых данных.


**Результат:** Изучены основные опции утилиты grep:
- `-i` — игнорировать регистр

## 4. Переменные и потоковая обработка

### 4.1 Изучение мануала sed

```bash
man sed
```

**Результат:** Изучена утилита sed (stream editor) — потоковый редактор текста. Основные команды:
- `s/pattern/replacement/` — замена первого совпадения в строке
- `s/pattern/replacement/g` — глобальная замена всех совпадений
- `1i\ text` — вставка текста перед первой строкой (i = insert)
- `d` — удаление строк
- `-n` — подавление автоматического вывода

### 4.2 Создание переменной

```bash
name='Lambert Wilson'
echo $name
```

## Заключение

В ходе лабораторной работы были успешно освоены:

1. **Перенаправление потоков**: перенаправление STDOUT (1) в файлы, перенаправление STDERR (2), объединение обоих потоков в один файл с помощью оператора `2>&1`.

2. **Пайплайн**: использование оператора `|` для связи команд в цепочку, последовательная фильтрация данных несколькими утилитами (cat, grep, sed, wc).

3. **Переменные и потоковая обработка**: создание и использование переменных в bash-командах, применение sed для замены текста, создание циклов while для обработки строк файлов с автоматической нумерацией.

Практическая применимость: полученные навыки позволяют эффективно анализировать большие текстовые файлы, автоматизировать обработку данных и создавать сложные команды для решения реальных задач администрирования и обработки информации в Linux.

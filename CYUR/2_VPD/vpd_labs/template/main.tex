\abstract{
В данной работе проведено экспериментальное исследование траекторий робота при движении по замкнутому пути. Реализованы и проанализированы два типа регуляторов управления: пропорциональный (П) и касательный (Tangential). Разработаны математические модели дифференциального привода с учетом одометрических вычислений координат. Построены модели в Simulink для симуляции движения. Проведен сравнительный анализ экспериментальных данных и результатов моделирования. Определены параметры метамодели, описывающей динамику робота.
}

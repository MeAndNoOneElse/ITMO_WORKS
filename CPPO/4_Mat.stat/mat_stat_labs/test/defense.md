Краткие тезисы для защиты лабораторной работы — Простая линейная регрессия

Цель документа

- Дать краткое понятное объяснение теории простой линейной регрессии и обозначений (чтобы быстро рассказать на защите).

1. Модель и обозначения

- Модель: y_i = β0 + β1 x_i + ε_i
  - y_i — значение зависимой (отклика) переменной в наблюдении i.
  - x_i — значение независимой (объясняющей) переменной в наблюдении i.
  - β0 (бета ноль) — свободный член (интерсепт). Это значение ŷ при x = 0.
  - β1 (бета один) — коэффициент наклона (склон). Показывает, на сколько в среднем меняется y при увеличении x на 1 единицу.
  - ε_i — случайная ошибка (остаток) в наблюдении i, предполагается E[ε_i]=0, Var(ε_i)=σ².

- Размер выборки: n — число наблюдений.
- Средние: x̄ = (1/n) Σ x_i, ȳ = (1/n) Σ y_i.

2. Оценки МНК (Метод Наименьших Квадратов)

- S_xx = Σ (x_i - x̄)²
- S_xy = Σ (x_i - x̄)(y_i - ȳ)

- Оценки коэффициентов (точечные):
  - β̂1 = S_xy / S_xx
  - β̂0 = ȳ − β̂1 x̄

- Прогноз (оценка функции регрессии) для произвольного x0:
  - ŷ(x0) = β̂0 + β̂1 x0

- Остатки: e_i = y_i − ŷ_i

3. Оценка дисперсии ошибки и статистические характеристики

- Остаточная сумма квадратов (RSS) = Σ e_i²
- Оценка дисперсии ошибок: s² = RSS / (n − 2)
- Остаточное стандартное отклонение: s = √s²

- Стандартная ошибка для β̂1:
  - SE(β̂1) = s / √(S_xx)
- Стандартная ошибка для β̂0:
  - SE(β̂0) = s * √(1/n + x̄² / S_xx)

4. Доверительные интервалы (CI) для коэффициентов

- Для уровня значимости α (обычно α = 0.05) критическое значение распределения Стьюдента: t_{1−α/2, df=n−2}.

- 95% CI для β1:
  - β̂1 ± t_{1−α/2, n−2} * SE(β̂1)

- 95% CI для β0:
  - β̂0 ± t_{1−α/2, n−2} * SE(β̂0)

Интерпретация: если 0 лежит внутри CI для β1, то при выбранном уровне значимости нет оснований считать коэффициент отличным от нуля (зависимость статистически незначима).

5. Коэффициент детерминации R²

- TSS (общая сумма квадратов) = Σ (y_i − ȳ)²
- R² = 1 − RSS / TSS

Интерпретация: доля дисперсии y, объясняемая моделью. Например, R² = 0.886 → 88.6% изменчивости y объясняется линейной зависимостью от x.

6. Основные статистические предположения модели

- Линейность: модель правильно задаётся как линейная функция от x.
- Независимость ошибок: ε_i независимы.
- Гомоскедастичность: Var(ε_i) = const = σ² (стандартное отклонение ошибок не зависит от i).
- Нормальность ошибок: ε_i ~ N(0, σ²) (необязательно для оценивания, но нужна для построения точных CI и тестов).

7. Диагностика (коротко, на случай вопросов)

- Построить график остатков e_i против x_i: если вид случайный (без тренда) — гомоскедастичность и линейность вероятно ок.
- Проверка нормальности остатков: Shapiro-Wilk или Q-Q plot.
- Поиск выбросов и влиятельных наблюдений: расстояния Кука, leverage.

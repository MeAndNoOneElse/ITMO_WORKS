# Линейная алгебра
- Преподаватели: [Карпова Дмитрий Валерьевич](https://logic.pdmi.ras.ru/~dvk/)
- [Пастор Алексей Владимирович ](https://logic.pdmi.ras.ru/~pastor/)
- Результат: 1ый сем 4C, 2ой - 3D, в итоге 4C
## Описание
- В течение семестра проводилось по 2-3 кр с возможностью переписать, но оценка ставилась только на экзамене.
- кр являются просто допуском к экзамену.
- На лекция иногда бывало весело, с шутками, но обычно, ты сидишь, пытаешься понять хоть что-то, но безуспешно, потом дома снова читаешь лекцию пару раз, и только потом что-то проясняется. Но глобальное осознание приходит только перед экзаменом и то, не всегда...
## Отзыв
ООчень много материала, лекции по 3 часа это тяжело. Пришлось всё учить...  
Не знаю, на сколько полезно, пока я полученные знания нигде не применял. 
Из полезного только матрицы были.
⭐⭐⭐⭐☆☆☆☆☆☆ (4/10)

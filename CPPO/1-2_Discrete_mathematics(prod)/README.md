# Дискретная математика
- Преподаватели: [Карпова Дмитрий Валерьевич](https://logic.pdmi.ras.ru/~dvk/)
- [Пастор Алексей Владимирович ](https://logic.pdmi.ras.ru/~pastor/)
- Результат: 1ый сем зачёт, 2ой - 4C
## Описание
- курс вели 2 лектора: Карпов по графам, Пастор по общей дискретке. Материала очень много на лекциях.
- В течение семестра проводилось по 2 кр с возможностью переписать, но оценка ставилась только на экзамене и кр являются просто допуском к экзамену.
- На лекция рассказывают всё строго по презентации, отклоняются только на вопросы.
## Отзыв
ООчень много материала, лекции по 3 часа это тяжело. Пришлось всё учить...  
Не знаю, на сколько полезно, пока я полученные знания нигде не применял. Графы ещё более менее, а остальное - бредик какой-то...
